# Controladores

Esta carpeta contiene las funciones que atienden las peticiones HTTP. Coordinan validaciones, modelos y respuestas (HTML, JSON o redirecciones), y envían los errores al middleware de Express.

- `productsController.js`: listado HTML/JSON y operaciones sobre productos.
- `authController.js`: formularios de acceso, autenticación y cierre de sesión.
